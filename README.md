# SIGEA — Sistema Integrado de Gestão de Espaços e Ambientes (EasyReserve Web)

Interface web institucional desenvolvida em **React + Vite + TypeScript + Tailwind CSS**, seguindo o design **SEI / Gestão de Espaços (PROINFRA)** e integrada à API `easy-reserve-api` (`http://localhost:9011/api/v1`).

## 🚀 Como Executar

1. Acesse a pasta do projeto frontend:
   ```bash
   cd K:\spring-projects\easy-reserve-web
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

4. Acesse no navegador:
   - `http://localhost:5173`
